# Primitive DB

Учебная консольная база данных на Python с поддержкой управления таблицами и CRUD-операций.

Приложение позволяет создавать таблицы, добавлять, просматривать, изменять и удалять записи. Данные сохраняются в JSON-файлах и остаются доступными после перезапуска программы.

## Установка и запуск

Для установки зависимостей и запуска приложения выполните:

```powershell
uv sync
uv run database
```

После сборки и установки пакета как отдельной программы базу данных можно запускать командой:

```powershell
database
```

## Управление таблицами

Доступны следующие команды:

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Выйти из программы |

Поддерживаются типы данных `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`, если пользователь его не указал.

Пример:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users
```

## CRUD-операции

Приложение поддерживает полный набор операций с записями: добавление (Create), чтение (Read), изменение (Update) и удаление (Delete).

### Доступные команды

| Команда | Описание |
|---|---|
| `insert into <таблица> values (...)` | Добавить запись |
| `select from <таблица>` | Показать все записи |
| `select from <таблица> where <столбец> = <значение>` | Найти записи по условию |
| `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` | Изменить записи |
| `delete from <таблица> where <столбец> = <значение>` | Удалить записи |
| `info <таблица>` | Показать структуру и количество записей |

### Пример использования

После создания таблицы `users` добавим две записи:

```text
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: insert into users values ("Anna", 24, false)
Запись с ID=2 успешно добавлена в таблицу "users".
```

Посмотрим содержимое таблицы:

```text
>>>Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
| 2  |  Anna  |  24 |   False   |
+----+--------+-----+-----------+
```

Найдём запись по условию:

```text
>>>Введите команду: select from users where age = 28
```

Изменим возраст пользователя:

```text
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
```

Удалим запись:

```text
>>>Введите команду: delete from users where name = "Anna"
Запись с ID=2 успешно удалена из таблицы "users".
```

Получим информацию о таблице:

```text
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 1
```

### Особенности работы

- Поддерживаются типы данных `int`, `str`, `bool`.
- Столбец `ID:int` создаётся автоматически.
- Идентификаторы записей назначаются программой.
- Все поля обязательны.
- Строковые значения необходимо заключать в двойные кавычки.
- Логические значения вводятся как `true` или `false`.
- Перед добавлением и изменением записей проверяются типы данных.
- Вывод результатов `select` оформляется с помощью библиотеки PrettyTable.
- Условия `where` позволяют находить, изменять и удалять подходящие записи.
- При удалении таблицы удаляется и соответствующий JSON-файл.

## Хранение данных

Метаданные таблиц, включая их названия и структуру столбцов, сохраняются в файле `db_meta.json`.

Записи каждой таблицы хранятся в отдельных JSON-файлах внутри директории `data/`.

Например, записи таблицы `users` сохраняются в `data/users.json`.

Все изменения сохраняются на диске и доступны после повторного запуска приложения.
