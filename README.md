## Управление таблицами

Приложение позволяет создавать, просматривать и удалять таблицы базы данных.
Метаданные таблиц сохраняются в JSON-файле `db_meta.json`.

### Запуск

```
uv sync
uv run database
```

### Доступные команды

 - `create_table <имя_таблицы> <столбец:тип> ...` - создать таблицу.
 - `list_tables` - вывести список таблиц.
 - `drop_table <имя_таблицы>` - удалить таблицу.
 - `help` - показать справку.
 - `exit` - выйти из программы.

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец `ID:int`.

### Пример использования

```
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: list_tables
Таблиц пока нет.

>>>Введите команду: exit
```

Изменения сохраняются в JSON-файле и доступны после перезапуска программы.
